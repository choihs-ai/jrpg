# 설계 문서 — 별빛 종의 이방인 제1장 · 제2장

## 1. 분석과 계획

시작 시점의 저장소는 `README.md`만 있는 빈 프로젝트였다. 기술 스택이 정해져 있지 않았으므로 **브라우저에서 바로 실행되는 바닐라 JS + Canvas + Web Audio**를 선택했다(설치 불필요, 모바일 사파리 지원, 외부 에셋 라이선스 문제 없음, 로직을 Node에서 테스트 가능).

개발은 요구된 8단계 순서를 따랐고, 각 단계마다 헤드리스 브라우저로 실제 실행·스크린샷을 확인했다.

| 단계 | 내용 | 검증 |
|---|---|---|
| 1 | 엔진(레이어·루프·입력), 타일·스프라이트, 이동·충돌·카메라 | 스크린샷 |
| 2 | 리벨 마을·실내, NPC 대화, 상호작용, 맵 전환, 이벤트 스크립트 API | 맵 검증기, E2E |
| 3 | BattleCore(순수 로직) + 전투 화면, 적 AI, 보스 패턴 | 단위 테스트, 시뮬레이션 |
| 4 | 경험치·레벨업·습득 기술, 파티 편성, 필드 주문 | 단위 테스트, E2E |
| 5 | 상점(구매·판매·비교), 장비, 인벤토리 | 단위 테스트, E2E |
| 6 | 평원·유적·보스·메인/서브 퀘스트·분기 | 맵 검증기(관문), E2E 2종 |
| 7 | 저장/불러오기, 설정, 지도, BGM·효과음, 연출 | E2E(왕복 검증) |
| 8 | 전체 플레이 테스트, 밸런스 조정, 버그 수정 | 전 테스트 통과 |

## 2. 세계관과 이야기

- **세계**: 아스텔 왕국 북쪽 변경. 고대 아스트라 문명이 남긴 「다섯 개의 종」이 세계와 무언가를 가르는 「장막」을 지킨다.
- **주인공**: 막차 버스에서 잠들었다가 이세계로 온 아르바이트생. 손등의 별 낙인은 「별의 열쇠」.
- **제1장 흐름**: 여관에서 깨어남 → 장로(별의 손님 전설) → 사냥꾼(회색 외투의 남자 목격) → 북쪽 고개의 철엄니와 리네트 → 유적의 별의 봉인 → 신전에서 미오 합류(별빛 방울) → 유적 탐험 → 타락한 종지기 벨가르 → 반전 → 장로에게 보고, 왕도로 향하는 결의.

### 반전과 복선
| 반전 | 복선 |
|---|---|
| 여관의 학자 오스릭이 「잿빛 성가대」이며 종을 울려 주인공을 불러낸 장본인 | 낙인을 지나치게 관심 있게 봄 / 사냥꾼이 본 회색 외투의 남자 / 넬이 지도를 판 상대 / 300년 전 금화로 숙박비 지불 / 여관 나그네 증언 |
| 오스릭 = 리네트의 실종된 스승 알드윈 교수 | 오스릭의 대사 「질문은 등불」= 리네트가 소개한 스승의 좌우명 / 유적의 쪽지 서명 「A.」와 리네트가 알아본 필체 |
| 주인공의 낙인은 종을 여는 열쇠 | 장로의 책 「별의 열쇠」 / 봉인 문양에 낙인이 반응 / 쪽지 「종은 열쇠를 부르고…」 |

### 분기
- **사라진 물건들**: 도둑 넬을 경비대에 넘기면 300G + 경비대 증표(이후 탈옥 후일담), 용서하면 넬이 동료로 합류하고 반지·파이프를 직접 돌려주는 후속 대화.
- **버섯왕**: 약초를 바치거나 결투.

## 3. 시스템

### 전투 공식
- 물리: `atk² / (atk + def) × 배율 × (0.88~1.12) × 속성` — 방어가 높아도 0이 되지 않는 비율식. 회심은 방어 무시 1.5배.
- 마법: `(위력 + 마력 × 계수) × (0.92~1.08) × 속성`. 방어 중이면 모든 피해 절반.
- 명중: 95% × 명중 버프 × (1 − 회피). 잠들거나 마비된 대상은 반드시 명중.
- 행동 순서: 민첩 × (0.75~1.25), 방어·우선 특기(분석·감싸기·철벽)는 항상 먼저.
- 오류 방지: 행동자당 라운드 1회, 쓰러진 행동자 건너뜀, 대상이 쓰러졌으면 재지정, 실행 시점에 MP·침묵·도구 수량 재확인, 같은 도구를 여러 명이 고르면 예약 수량 반영.

### 성장
- 능력치 = 기본 + 성장률 × (Lv−1) + 약간의 가속. 경험치 표: Lv2 12 · Lv4 118 · Lv6 396 · Lv8 915 · Lv10 1739.
- 전투 멤버는 전체 경험치, 대기 멤버는 절반. 늦게 합류한 동료는 주인공 레벨−1에 맞춰진다.

### 진행도와 대사
`Game.progress()`가 0(깨어남) ~ 8(1장 완료)를 반환하고, NPC는 `byP({0:…, 3:…})`로 진행도에 맞는 대사를 고른다. 퀘스트 상태·플래그에 따라서도 분기한다.

### 막힘 방지
- 맵 검증기가 모든 워프 착지점·NPC·오브젝트·트리거의 도달 가능성, 진행 관문(봉인 전 유적 안쪽·철엄니 뒤 유적)을 확인한다.
- 맵 진입 좌표가 막혀 있으면 가장 가까운 빈 칸으로 보정한다.
- 전멸해도 신전에서 부활(소지금 절반)하고 퀘스트·보스는 다시 도전 가능.
- 이벤트 스크립트에서 예외가 나도 busy 상태를 복구하고 게임은 계속된다.

## 5. 제2장 「왕도로 가는 길」

### 흐름
리벨 장로의 배웅 → 평원 동쪽 끝의 은빛 가도 → 역참 → 은빛 다리에서 잿빛 성가대 집행자 베인(악보: 「제2성부는 시간의 종 아래에서」) → 별내림 축제 중인 왕도 아스테리온 → 마도학원 오필리아 학장(시간의 종 = 학원 시계탑 아래, 탑은 시간이 멈춰 봉쇄 / 알드윈의 딸 엘리가 20년 전 회색병으로 사망) → 수호기사단 라인하르트 단장(브란의 아버지 드른이 전설의 기사였다는 사실) → 브란 혼자 싸우는 입단 시험 → 시간이 얼어붙은 탑 문 → 옛 물시계 수로를 통한 우회(수로 관리인 오토) → 지하수로(수문 퍼즐, 늙은 이빨, 오스릭의 야영지와 엘리의 편지) → 시계탑(멈춘 먼지, 자정의 문 시계판 퍼즐) → 제2성부 카산드라(넬의 친언니) → 시간의 종이 보여 준 환영(원래 세계의 병실에서 잠든 주인공) → 오스릭의 목적 고백, 종의 심장이 주인공을 택함 → 「별의 수호대」 결성, 제3장 「사막의 종」 예고.

### 동료별 이야기
| 동료 | 2장의 축 |
|---|---|
| 브란 | 아버지가 동료를 잃고 검을 꺾은 기사였다는 진실 → 일대일 입단 시험 → 견습 기사의 방패 |
| 리네트 | 스승의 숨겨진 과거(딸 엘리) → 「죽은 사람은 돌아오지 않는다」는 대립 |
| 넬 | 왕도 보육원 출신, 8년 전 성가대를 따라간 언니 카산드라와의 재회. 1장에서 감옥에 보냈다면 탈옥 후 보육원에 있다가 동료로 합류 |
| 미오 | 종의 노래를 따라 길을 찾고, 쓰러진 주인공을 붙잡는다 |
| 주인공 | 원래 세계의 몸이 병실에 잠들어 있다는 환영 → 「돌아가려면 장막을 열어야 한다」는 유혹과 「열쇠는 닫을 수도 있다」는 복선 |

### 새 전투 요소
- **처형 선고(베인)**: 지정된 동료에게 다음 턴 2배 일격 → 방어·감싸기·수호의 맹세로 대응.
- **일대일 시험(가웨인)**: `BattleCore({ party: ['bran'] })`. 져도 게임오버 없이 재도전(`loseOk`).
- **잠수(늙은 이빨)**: 예고와 함께 방어력 상승 → 다음 턴 회전 공격.
- **결계(카산드라)**: `def.barrier`가 참이면 받는 피해 50%. 시계태엽 수호자를 먼저 쓰러뜨리는 것이 정석. 「되감기」(대량 회복)는 예고 후 시전되며 침묵의 봉인으로 막을 수 있다. 2단계에서 정지의 종소리(전체 민첩 감소)와 2회 행동.
- **도감(기억)**: 속성 공격·분석으로 드러난 상성은 `Game.state.known`에 영구 기록, 대상 선택 창에 표시.

### 진행도
`Game.progress()` 9(출발) · 10(베인) · 11(왕도) · 12(학장) · 13(입단) · 14(늙은 이빨) · 15(카산드라) · 16(2장 완료).
