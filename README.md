# 별빛 종의 이방인 (Stranger of the Starlit Bell)

브라우저에서 바로 실행되는 **이세계 정통 JRPG**입니다. 제1장 「잠든 종의 유적」을 처음부터 끝까지 플레이할 수 있습니다.

> 막차 버스에서 잠든 평범한 아르바이트생이 이세계의 들판에서 눈을 뜬다. 손등에는 별 모양의 낙인.
> 같은 밤, 300년 동안 잠들어 있던 북쪽 유적의 종이 울렸다—.

## 실행 방법

| 방법 | 설명 |
|---|---|
| 그냥 열기 | `index.html`을 브라우저로 연다 (빌드·서버 불필요, `file://`에서도 동작) |
| 단일 파일 | `node tools/build.mjs` → `dist/starbell-jrpg.html` 파일 하나로 어디서든 실행 (오프라인·아이폰 사파리 포함) |
| 로컬 서버 | `npx serve .` 등 아무 정적 서버 |

## 게임 내용

- **맵**: 리벨 마을(실내 10곳), 초록바람 평원(월드 필드), 잠든 종의 유적 B1·B2·종의 방, 우물 아래 동굴, 사냥꾼의 오두막
- **동료 5명** (전투 참가 최대 4명, 편성 가능): 이방인(주인공) · 수호기사 지망생 브란 · 마도학자 리네트 · 종의 무녀 미오 · 떠돌이 도적 넬(선택에 따라 합류)
- **턴제 전투**: 공격 / 주문 / 특기 / 도구 / 방어 / 도망, 속도 기반 행동 순서, 물리·마법 구분, 명중·회심, 5속성(불·얼음·번개·빛·어둠) 상성, 독·수면·마비·침묵, 버프/디버프, 감싸기·도발, 훔치기, 적 AI
- **보스**: 철엄니(돌진 예고 → 방어 필요, 체력이 줄면 졸개 소환·분노), 벨가르(종 울림 예고 → 전체 공격, 체력 절반에서 약점이 드러나는 2단계·그림자 소환·흡수), 버섯왕(회복·디버프)
- **성장**: 레벨업 능력치 상승, 레벨별 주문·특기 습득, 장비 5부위(무기·갑옷·방패·투구·장신구)
- **퀘스트**: 메인 2 + 서브 7 (수집·토벌·탐색·배달·조사·선택 분기·수집가), NPC 대사는 진행도·퀘스트 상태에 따라 변화
- **탐험 보상**: 보물상자(가짜 상자 포함), 술통·항아리·서랍 조사, 숨겨진 땅(넬이 있으면 반짝임), 비밀 나무 통로, 무너지는 벽, 별조각 8개 수집
- **저장**: 3슬롯 (메뉴·신전·유적의 수정), 설정은 별도 저장
- **그래픽·사운드**: 외부 리소스 없이 전부 코드로 생성 (픽셀아트 타일·캐릭터·몬스터, Web Audio 칩튠 BGM 11곡 + 징글 + 효과음) → 라이선스 문제 없음

## 기술 스택과 선택 이유

**바닐라 JavaScript + HTML5 Canvas 2D + Web Audio API (의존성 0)**

- 설치·빌드 없이 브라우저에서 바로 실행 — PC, 아이폰/아이패드 사파리, 안드로이드 모두
- 오프라인 동작, 단일 HTML 배포 가능
- 그래픽·음악을 코드로 생성해 외부 에셋 라이선스 문제가 없음
- 게임 로직(전투·성장·퀘스트·저장)을 DOM과 분리해 Node에서 단위 테스트·밸런스 시뮬레이션 가능

## 프로젝트 구조

```
index.html, style.css      진입점 (스크립트 순서대로 로드)
src/core/      util(난수·한국어 조사) · input(키보드/마우스/터치) · engine(레이어·루프·화면효과) · audio(칩튠 시퀀서)
src/ui/        text(줄바꿈·색 마크업) · widgets(대화창·목록·수량·이름 입력)
src/gfx/       pixel · tiles · chars · monsters · objects  — 절차적 픽셀아트
src/data/      items · skills · characters · monsters(+인카운터) · talk(동료 대화)
src/systems/   game(상태·파티·인벤토리) · quests · save · settings · battlecore(전투 규칙)
src/maps/      legend · maps · rivel · field · dungeons · story(컷신)
src/scenes/    events(스크립트 API) · field · battle · menu · shop · mapview · title
src/main.js    부팅·새 게임·불러오기
tools/build.mjs           단일 HTML 빌드
tests/                    단위 테스트 · 맵 검증 · 밸런스 시뮬 · E2E 자동 플레이
docs/DESIGN.md            설계 문서 (세계관·시스템·밸런스)
```

## 테스트

```bash
node tests/unit.mjs            # 전투 규칙·장비·성장·퀘스트·저장 단위 테스트 (33개)
node tests/validate-maps.mjs   # 맵 크기·타일·워프 착지점·NPC/오브젝트 배치·도달 가능성·진행 관문 검증
node tests/sim-balance.mjs     # 실제 전투 로직으로 주요 전투 수백 회 시뮬레이션
node tests/e2e.mjs             # 실제 키 입력으로 제1장 전체 자동 플레이 + 저장/불러오기 검증 (Playwright)
node tests/e2e-side.mjs        # 서브 퀘스트 전 분기·여관·게임오버·도망·편성 등 자동 플레이
```

E2E는 Playwright(Chromium)가 필요합니다. 보스 직전에는 테스트 시간을 줄이기 위해 경험치를 보정합니다(밸런스는 시뮬레이션으로 따로 검증).
